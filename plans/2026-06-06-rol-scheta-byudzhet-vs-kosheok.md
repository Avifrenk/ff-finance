# Роль счёта: бюджет месяца vs кошелёк-накопления

## Контекст / задача

Сейчас «Общий баланс» в дашборде — одна цифра, в которой сложено всё:
и накопленный остаток (то что лежит «в кошельке»), и деньги, выделенные на
этот месяц на личные траты. Это ментально неверно: владелец держит
конверты в голове («3 600 на июнь на себя, 12 140 — накопления»), но
система их не различает.

Хотим:

1. У счёта появляется **роль**: `wallet` (накопления, по умолчанию)
   или `monthly_budget` (бюджетный конверт месяца).
2. Конверт месяца знает свой **месячный лимит** (`monthly_amount`).
3. В форме операции — выбор счёта (уже работает); группировка
   «бюджеты / накопления» в селекте — желательно.
4. На дашборде вместо одной цифры «Общий баланс» — два блока:
   * 💰 **Бюджет месяца**: остаток / лимит (по всем `monthly_budget` счетам).
   * 🏦 **Накопления**: по всем `wallet` счетам.
   * Это работает и для личного, и для семейного кабинета.

## Решения

* Не делаем отдельную сущность «envelope» — расширяем `accounts`. Это
  минимальная миграция; механика операций / переводов уже подходит.
* Автообнуление конверта в начале месяца — **вне скоупа этого плана**
  (следующая фаза: кнопка «Открыть новый месяц» или cron).
* Базовая валюта суммирования — `household.base_currency`, как сейчас
  в `totalBalance`.

## Фазы

### Фаза 1. Миграция БД [x]

* `accounts.role text not null default 'wallet' check (role in ('wallet','monthly_budget'))`.
* `accounts.monthly_amount numeric(14,2) null` — только для `monthly_budget`,
  для `wallet` остаётся NULL.
* Индекс не нужен — фильтрация в памяти.

### Фаза 2. Хук useAccounts [x]

* Поле `role` + `monthly_amount` в `Account` и `CreateAccountInput`.
* Параметры передаются при insert.

### Фаза 3. Settings → AccountsSection [x]

* В `AddAccountForm` — переключатель «🏦 Накопления / 💰 Бюджет месяца».
* Если выбран `monthly_budget` — поле «Месячный лимит» обязательно.
* В списке счетов — показывать иконку роли и сам лимит для бюджета.

### Фаза 4. Dashboard → блок баланса [x]

* Заменить `<section>` «Общий баланс» на блок с двумя строками:
  «Бюджет месяца» (X / N, прогресс-бар) и «Накопления» (Y).
* Считать в `baseCurrency` отдельно для каждой роли, через тот же
  `convertMoney`.
* Если бюджетных счетов нет — показываем только «Накопления» (как
  раньше); если только бюджет — показываем только его.

### Фаза 5. AddOperationDialog [x]

* Группировка `<optgroup>` в селекте «Счёт»: бюджеты сверху,
  накопления снизу. Текстом значка — '💰 ...' / '🏦 ...'.

### Фаза 6. Применить миграцию и проверить [x]

* `npm run db:push`.
* Завести «Бюджет июня 3 600 ₪» вручную через Settings.
* Открыть дашборд — убедиться что два блока, и общий баланс
  соответствует.

## Что отложено

* Автоматическое «закрытие месяца» (возврат остатка конверта в
  кошелёк + перевод 3 600 из кошелька в новый конверт).
* Подсветка превышения бюджета и сравнение с прошлыми месяцами.
* Перенос/редактирование роли существующего счёта (пока — только
  через создание нового).
