# Фаза 6 — AI-фичи

Источник: ROADMAP.md → «Фаза 6 — AI-фичи». Anthropic API-ключ уже зарегистрирован и хранится в `~/.config/ff-finance/anthropic-key` (chmod 600). Карта НЕ привязана, баланс $0 — для разработки достаточно free evaluation tier, но после первой реальной картинки/звонка пользователю нужно ОДНОЗНАЧНО ротировать ключ (он был засвечен в чате) и положить $5–20.

## Архитектура (черновик, требует согласования)

| Слой | Решение | Альтернативы |
|---|---|---|
| Где живёт ключ | `supabase secrets set ANTHROPIC_API_KEY` → читается из Edge Function | НЕ `.env.local` (Edge runtime его не видит) |
| Куда складываем фото чеков | Supabase Storage bucket `receipts`, RLS «owner-only» | base64 в БД — нет; внешний CDN — нет |
| SDK для Claude в Edge Function | `import Anthropic from "https://esm.sh/@anthropic-ai/sdk@0.x"` (Deno-совместимо через esm.sh) | npm-only — не подходит |
| Модель для Vision (чеки) | `claude-sonnet-4-6` через structured outputs (`output_config.format` + JSON schema) | Haiku 4.5 — хуже OCR; Opus 4.7 — дороже без видимого выигрыша |
| Модель для AI-ассистента (чат) | `claude-sonnet-4-6` + adaptive thinking + prompt caching системного промта | Haiku — теряем точность по агрегациям |
| Модель для еженедельного дайджеста | `claude-haiku-4-5` (одна короткая генерация в неделю → копейки) | Sonnet — overkill |
| Голосовой ввод (Whisper) | OpenAI Whisper API ($0.006/мин), отдельный ключ позже; или Web Speech API на клиенте (бесплатно, но качество хуже) | На клиенте — быстрее MVP, в проде заменим |
| Прайс-cap | Edge Function `parse-receipt`: hard limit 1 фото на вызов, max ~4K input + 2K output на чек ≈ $0.05 за фото. AI-чат: max 4 запроса/минуту через RLS-чек | — |

### Структура БД (новые таблицы)

```sql
-- Фаза 6.1: история парсинга чеков (для аналитики и retry)
create table public.ai_receipt_scans (
  id              uuid primary key default gen_random_uuid(),
  household_id    uuid not null references public.households(id) on delete cascade,
  author_profile_id uuid not null references public.profiles(id) on delete restrict,
  storage_path    text not null,           -- путь в bucket receipts/
  status          text not null check (status in ('pending','parsed','failed','applied')),
  parsed_json     jsonb,                   -- ответ от Claude
  applied_operation_id uuid references public.operations(id) on delete set null,
  tokens_in       int,
  tokens_out      int,
  cost_usd        numeric(10,4),
  error_message   text,
  created_at      timestamptz not null default now()
);

-- Фаза 6.3: история AI-чата (на пользователя, не на household)
create table public.ai_chat_messages (
  id              uuid primary key default gen_random_uuid(),
  profile_id      uuid not null references public.profiles(id) on delete cascade,
  household_id    uuid not null references public.households(id) on delete cascade,
  role            text not null check (role in ('user','assistant')),
  content         text not null,
  tokens_in       int,
  tokens_out      int,
  created_at      timestamptz not null default now()
);
```

RLS: владелец видит только свои строки. `service_role` (Edge Function) пишет от имени `author_profile_id` через `supabase.auth.getUser(jwt)`.

## Фазы

### Фаза 6.1 — Vision: фото чека → распарсенные позиции
- [x] Миграция `20260530700000_ai_receipts.sql`: таблица `ai_receipt_scans`, bucket `receipts` с RLS «owner can upload/read own folder», GRANTы для `authenticated`.
- [x] Edge Function `ai-parse-receipt`:
  - принимает `{ scan_id }` от клиента (через `verify_jwt = true` по умолчанию);
  - читает фото из Storage по `storage_path` под service_role;
  - вызывает `claude-sonnet-4-6` с image-блоком + structured output (JSON-schema: `{vendor, date, currency, total, items: [{name, price, quantity, category_hint}]}`);
  - сохраняет `parsed_json`, `tokens_in/out`, `cost_usd` в `ai_receipt_scans`;
  - возвращает результат клиенту.
- [x] UI: новая страница `/scan-receipt` — `<input type="file" accept="image/*" capture="environment">`, превью, кнопка «Распознать», экран подтверждения (можно править поля), «Сохранить операцию» → создаёт `operations` row + проставляет `applied_operation_id`.
- [x] Категорию определяет Claude по `category_hint` + матчинг к существующим `categories` через `ilike '%name%'` + дефолт первой expense-категории, финальный выбор — за пользователем.
- [x] Добавлены вкладки «📸 Сканер» в шапке (десктоп) и bottom-bar (мобайл).
- [x] Применена миграция (`npm run db:push`), задеплоена функция (`supabase functions deploy ai-parse-receipt`), залит `ANTHROPIC_API_KEY` в Supabase secrets.
- [x] Задеплоен фронт через `npm run deploy` → доступно на https://avifrenk.github.io/ff-finance/scan-receipt.
- [ ] Тестирование на реальном израильском чеке (Шуферсаль/Рами Леви). Запись в `.business/история/`.

### Фаза 6.3 — AI-ассистент в приложении ✅
- [x] Миграция `20260530710000_ai_chat.sql`: таблица `ai_chat_messages` (profile_id, household_id, role, content, tokens_in/out), RLS «владелец видит только свои».
- [x] Edge Function `ai-chat`:
  - принимает `{ user_message }`;
  - подтягивает контекст: текущий household, последние 30 дней операций (top 200), активные бюджеты текущего месяца, незаархивированные цели с прогрессом, балансы счетов;
  - формирует system как массив из двух текстовых блоков; второй (контекст) помечен `cache_control: ephemeral` → 5-минутный кеш-хит на повторных вопросах;
  - вызывает `claude-sonnet-4-6` с `thinking: { type: "enabled", budget_tokens: 2000 }` (выбрал enabled вместо adaptive — предсказуемее по стоимости) + предоставляет tools `sum_by_category(month, kind)`, `get_balance(account_id?)`, `compare_months(month_a, month_b)` — выполняются у нас через Postgres-запросы и возвращаются модели;
  - SSE-стрим ответа клиенту (`{type:"chunk"|"tool"|"done"|"error"}`); промежуточные раунды tool_use обрабатываются non-stream, финальный текст стримится 40-символьными кусками для плавности UI;
  - пишет user+assistant сообщения в `ai_chat_messages` под service_role.
- [x] UI: страница `/assistant` — чат-интерфейс с пузырями, история на пользователя, кнопка «Очистить», 4 подсказки-стартера, индикация выполняемого tool.
- [x] Лимит: 50 user-сообщений/день на профиль (проверка `count(*) WHERE role='user' AND created_at >= today` перед обработкой → HTTP 429).
- [x] Навигация: иконка 💬 «Финик» добавлена в шапку (NavItem) и bottom-bar (TabItem, grid-cols-7 → grid-cols-8).
- [x] Деплой: миграция применена (`npm run db:push`), функция задеплоена (`supabase functions deploy ai-chat`), фронт — на https://avifrenk.github.io/ff-finance/assistant.
