# План: веб-страница `/flights` (Фаза 3 модуля «Авиабилеты»)

Деталь Фазы 3 зонтичного плана `2026-06-06-modul-aviabilety.md`. Один план =
одна функция: здесь — только веб-интерфейс управления маршрутами в PWA.

## Цель

Дать «веб-лицо» движку EasyTicket: семья видит и заводит маршруты слежки за
ценами прямо в Frenkel Finance. Бот остаётся «безголовым» (опрос + триггер +
Telegram-пуш) — веб только управляет маршрутами и **читает** наблюдения/алерты.

**Граница продукта (не нарушать):** авиабилеты — отдельный продукт внутри
оболочки финтрекера. Никакой связи с тратами/бюджетами/целями/P&L. Делим только
оболочку (auth/household/навигация).

UX-фильтр каждого экрана: «Алина поймёт с первого раза без объяснений».

## Что веб делает / не делает с данными

- `flight_routes` — читает/создаёт/архивирует/удаляет (RLS: только своя семья).
- `flight_observations`, `flight_alerts` — **только читает** (пишет бот).
- `flight_telegram_links` — каждый правит только свою связку (профиль↔chat_id).

При INSERT маршрута: `household_id` = текущая household, `created_by_profile_id`
= `auth.uid()`, `owner_chat_id` = `chat_id` создателя из `flight_telegram_links`.
Без привязки Telegram маршрут создать нельзя (боту некуда слать пуш).
